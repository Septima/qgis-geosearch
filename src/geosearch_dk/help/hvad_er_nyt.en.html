Geosearch DK 4.0 – now with Bifrost

The Danish Agency for Climate Data (Klimadatastyrelsen) closes the search service GSearch in November 2026. Geosearch DK therefore now uses the agency's new search service, Bifrost. Most things work as before, but there are some differences.

You need a key for Bifrost

Bifrost requires its own API key. A Dataforsyningen token cannot be used, so the plugin has removed the token you may have entered in the old version.

The plugin does not have a built-in key, so you have to create a key and enter it yourself. As long as there is no key, the search panel shows a yellow bar. Click Enter key in the yellow bar or the wrench in the search panel (or choose Settings → Options → Geosearch DK), and paste it under Bifrost API key. How to create a user at Dataforsyningen. Your IT department can also set the key for everyone with the environment variable BIFROST_KEY.

Important: Cadastral numbers have become properties

Bifrost cannot search parcels, only properties. The search type Cadastral numbers is therefore now called Properties. When you search for a cadastral number, you find the whole property (BFE) that the parcel belongs to, and the map shows the whole property, not just the parcel. The exact cadastral number is at the top of the list. If the property is on more than one parcel, the list says so, e.g. 3kg, Vangede (del af ejendom med 27 matrikler).

Type ejd: first to search only properties, e.g. ejd: 3kg søllerød. mat: still works. See examples (in Danish)

New

  • Apartments: You can now find addresses with floor and door.

Works differently

  • The text in the result list is now made by the plugin. Place names are shown as name (type, municipality), e.g. Skodsborg (bebyggelse, Rudersdal).
  • The map first zooms to a point. The full geometry, e.g. a road or a property, follows a moment later.
  • The municipality filter is now an option you switch on yourself in the settings. Bifrost cannot filter by municipality, so the plugin fetches results for the whole country and hides those outside your municipalities. Be aware:
    • You can miss results. The plugin only looks at Bifrost's 100 best hits for the whole country. For example, cadastral number 1a with a filter on Horsens (615) gives no results, even though there are many. See examples (in Danish)
    • Addresses work best, because the plugin sends the municipality to Bifrost.
    • Large place names, e.g. a river or a region of the country, can be hidden, because they belong to only one municipality.
    • If you used the municipality filter in the old version, it is switched on. You can switch it off in the settings.

No longer works – and why

  • Searching for parts of words. nørrebrog no longer finds Nørrebrogade. Type whole words, e.g. nørrebrogade 1 københavn. On the other hand, Bifrost corrects small spelling mistakes.
    Why: Bifrost does not offer it. See examples (in Danish)
  • Municipality filter in the search service. GSearch filtered by municipality, so you got all hits in your municipalities. Now the plugin filters by itself, and that can give fewer results (see The municipality filter).
    Why: Bifrost does not offer it.
  • The subtype of place names. GSearch showed e.g. Skodsborg (By i Rudersdal Kommune). Now only a general type is shown, e.g. bebyggelse or naturareal, so places with the same name can be hard to tell apart.
    Why: Bifrost does not offer it. See examples (in Danish)
